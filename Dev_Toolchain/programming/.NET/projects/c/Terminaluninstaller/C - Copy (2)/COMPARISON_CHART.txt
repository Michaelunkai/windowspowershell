🛡️  PROTECTION COMPARISON

Both TURBO and NUCLEAR protect:
  ✓ Windows core system files (ntoskrnl.exe, kernel32.dll, etc.)
  ✓ Windows Boot directory
  ✓ Registry system hives (SYSTEM\config)
  ✓ Critical system processes (csrss, lsass, services, svchost)
  ✓ $Recycle.Bin and System Volume Information

NUCLEAR additionally protects:
  ✓ Non-app WinSxS components (scans but deletes selectively)
  ✓ Windows Update core files (scans but deletes app-specific only)

NUCLEAR is MORE AGGRESSIVE on:
  ✓ App-specific WinSxS manifests/components
  ✓ DriverStore cache (deeper scan)
  ✓ Windows Installer cache (more thorough)
  ✓ All user profiles (not just current)
  ✓ Shortcuts across all locations
